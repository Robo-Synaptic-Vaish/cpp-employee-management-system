# Employee Management System

A beginner-friendly **Employee Management System built in C++** using Object-Oriented Programming (OOP) concepts.

## 📌 About the Project

This project is a console-based application designed to manage employee records.

It is being developed step-by-step to practice core C++ concepts such as:

* Classes and Objects
* Encapsulation
* Constructors
* Functions
* Multiple source and header files
* Searching and managing records
* File Handling
* Git and GitHub workflow

## 🚀 Features

The planned features include:

* [x] Create an Employee class
* [x] Store employee information
* [x] Display employee information
* [ ] Add multiple employees
* [ ] Display all employees
* [ ] Search for an employee
* [ ] Update employee information
* [ ] Delete an employee
* [ ] File handling
* [ ] Interactive menu
* [ ] Persistent employee records

## 🛠️ Technologies Used

* **Language:** C++
* **Compiler:** GCC / MinGW
* **IDE:** Visual Studio Code
* **Version Control:** Git
* **Platform:** Windows

## ▶️ How to Run

Clone the repository and navigate into the project folder.

Compile the program using:

```bash
g++ src/main.cpp src/employee.cpp -o employee.exe
```

Run the program:

```bash
employee.exe
```
